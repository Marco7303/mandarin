# Mori logos for Stack Auth / Hexclave

Upload each PNG to the matching branding field:

| Field | File | Dimensions |
| --- | --- | --- |
| Logo | mori-logo-light.png | 200 × 200 px |
| Full Logo | mori-full-logo-light.png | 600 × 200 px |
| Logo (Dark Mode) | mori-logo-dark.png | 200 × 200 px |
| Full Logo (Dark Mode) | mori-full-logo-dark.png | 600 × 200 px |

All files have transparent backgrounds. The light versions use the site's green
mark and dark wordmark; the dark versions use an off-white mark and wordmark.
The square logo is the site's 森 symbol. The full logo includes “mori.”

The 森 symbol is rendered using the unchanged 教育部標準楷書 font supplied with
the app. Typeface credit: 中華民國教育部 (Ministry of Education, Taiwan),
CC BY-ND 3.0 TW. See ../../FONT-LICENSE.md for the font attribution and licence.
