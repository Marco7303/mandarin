# Taiwanese learning font

The supplied `edukai-5.1_20251208.ttf` identifies itself as **TW-MOE-Std-Kai / 教育部標準楷書**, version 5.1, December 2025. The OpenType `OS/2.fsType` is 0 (no embedding restriction). The `name` table expressly permits commercial and noncommercial redistribution of the entire unchanged file with credit to MOE, and identifies the licence as **Creative Commons Attribution–NoDerivs 3.0 Taiwan (CC BY-ND 3.0 TW)**.

Attribution: **中華民國教育部 (Ministry of Education, Republic of China / Taiwan)**.

The app serves an unchanged byte-for-byte copy at `public/fonts/edukai.ttf`. It has not been subsetted, converted, or modified. CSS rendering of the intact font preserves the original font file. Keep this attribution and licence notice when distributing the app or font.
